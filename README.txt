YSKN Dashboard - Paket HTML/CSS/JavaScript
1. Ekstrak ZIP.
2. Buka index.html di browser modern.
3. Pertahankan index.html, styles.css, dan script.js dalam folder yang sama.
4. Ikon dan font memakai CDN; untuk tampilan ikon/font lengkap diperlukan koneksi internet.
5. Tombol Ekspor data mengunduh CSV, tombol Cetak laporan membuka dialog cetak/simpan PDF.
6. Diagram dibuat dengan CSS, sehingga tidak memerlukan pustaka grafik eksternal.
